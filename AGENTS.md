# Instructions for AI coding agents

If a person asks you to set up, install or recover their own password vault with an encrypted off-site copy, read and follow
[`skill/vaultwarden-recovery-deploy/SKILL.md`](skill/vaultwarden-recovery-deploy/SKILL.md). It works on Linux and on Windows
(through WSL2). The most important rule: **never see, ask for or store the person's secrets**; they type or generate them
on their own terminal. Ask before each step that changes something.
