# Security and privacy / Seguridad y privacidad

**English.** This repository describes a design; it contains no secrets and describes no real installation. Never add passwords, passphrases, recovery codes, private keys, tokens, real hostnames, addresses, domains or backup files to it: `.gitignore` does not remove what was already committed. The scripts read every path and name from an environment file you keep private. They are reference code: read them, adapt them and test a restore before trusting them with real data. Report a weakness in the design or the scripts through a private channel agreed with the maintainer; do not open a public issue with details that could be used against someone's setup.

**Español.** Este repositorio describe un diseño; no contiene secretos ni describe ninguna instalación real. Nunca le agregues contraseñas, frases, códigos de recuperación, claves privadas, tokens, nombres de host reales, direcciones, dominios ni archivos de backup: `.gitignore` no quita lo que ya se subió. Los scripts leen cada ruta y nombre de un archivo de entorno que mantenés privado. Son código de referencia: leelos, adaptalos y probá una restauración antes de confiarles datos reales. Reportá una debilidad del diseño o de los scripts por un canal privado acordado con el mantenedor; no abras un issue público con detalles que puedan usarse contra la instalación de alguien.
